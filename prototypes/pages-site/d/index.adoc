[.features]
* *Compile-safe.* A renamed property breaks the build, not the test run. No more `hasProperty("naem")`.
* *Readable failures.* Every failing check gets one line with its property path: `customer.address.city: expected "Berlin" but was "Paris"`.
* *Completeness check.* A test fails when a new property is neither checked nor deliberately ignored.
