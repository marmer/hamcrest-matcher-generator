=== Requirements overview

* Generate Hamcrest matchers and AssertJ assertions for model classes at compile time.
* No production-code pollution: the configuration lives in test sources and uses a SOURCE-retention annotation.
* A compile-safe alternative to Hamcrest's `hasProperty()`.
* Readable mismatch messages with property paths.
* Plain Java, records, Lombok and Kotlin (via KAPT).
