[[section-glossary]]
== Glossary

[cols="e,2e" options="header"]
|===
|Term |Definition

|Property model
|The description of a configured type and its properties that does not depend on any assertion library. All backends share it.

|Property
|A readable value of a bean (via its getter) or a record (via its component accessor) that generated assertions can check.

|Backend
|A generator that turns the property model into assertion code for one specific assertion library, such as Hamcrest or AssertJ.

|Configuration
|The single annotation-based declaration of the types for which assertions are generated. It is the same for every backend.

|Reference object
|An instance of a configured type whose property values are used as the expected values for all of its properties, so that a whole object can be compared in one step.

|Property path
|The route from the asserted object to the value that was checked, written with dots between property names, `[index]` for list items and `[key]` for map entries. Mismatch messages use it to say exactly which value differs, for example `customer.address.city` or `lines[1].quantity`.

|Completeness check
|The check that every property of a type is either asserted or deliberately ignored. It makes sure that a property added later cannot go unchecked without anyone noticing.
|===
