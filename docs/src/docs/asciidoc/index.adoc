[.features]
* *Compile-safe.* The matchers and assertions come from your model classes. Rename a property and the test code that uses it stops compiling, instead of failing at run time.
* *Readable failures.* A mismatch names the property that differs, nested properties included, with the expected and the actual value.
* *Completeness check.* Opt in and a test fails when a property was neither checked nor ignored, so a property added to a model cannot slip by unasserted.

== Install

Add the generator for the backend you use, and Hamcrest or AssertJ next to it. The current release is {project-version}; the snippets read it from the property `hamcrest-matcher-generator.version` or `assertj-assertion-generator.version`, which you define once in your build.
