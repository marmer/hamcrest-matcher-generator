= Getting started
:description: Add the dependencies, configure the types and write a first test with generated matchers.
:page-order: 1

This chapter takes you from an empty Maven build to a first green test. The examples are Java. The Kotlin setup is documented in the README.

== Requirements

* Java 17 or newer. Since 6.0.0 the generated code needs Java 17; users who stay on Java 11 stay on 5.x.
* A test dependency on Hamcrest for the Hamcrest backend, or on AssertJ for the AssertJ backend. The examples use Hamcrest {hamcrest-version} and AssertJ {assertj-version}. You can use both backends in one project.

== Generated code

The processor writes the matchers and assertions as source files, and your build compiles them like code you wrote. The generated files carry `@Generated` and no license header.

The generated code belongs to you. It is not covered by the project's Apache License 2.0, so you can use it, change it and ship it in your own projects.
